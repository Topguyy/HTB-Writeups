# htb-writeups

Writeups from my HackTheBox journey - retired machines and CPTS module knowledge checks. Every writeup is posted only after the machine is retired or the module challenge is no longer active, in line with HTB's content policy.

I don't just document what worked - I document what didn't, why I went down certain paths, and what each box actually taught me.

## writeup format

Each writeup follows this structure:

- **Recon** — what I found and how
- **Foothold** — how I got in
- **Privilege escalation** — path to root/admin
- **What I learned** — the actual takeaway, not just the steps
- **What tripped me up** — honest notes on where I got stuck
- **Remediation Recommendation** — how to fix every vulnerability I exploited
